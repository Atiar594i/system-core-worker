# System Core Worker

High-performance event processing, dual-channel data pipeline, and real-time telemetry service.

## Cloud Deployment
Configured for automated container and serverless deployments with `render.yaml`.

## Features
- Multi-channel asynchronous event pipeline
- Zero-latency SSE streaming
- Adaptive backoff and worker pooling
- Microservice health checking and status monitoring

## Running
```bash
pip install -r requirements.txt
python server.py
```
